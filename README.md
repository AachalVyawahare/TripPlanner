# 🤖 AI Trip Planner

An intelligent multi-agent AI system that generates complete travel plans including destinations, budget, weather, hotels, and day-wise itinerary.

## 🚀 Features
- Multi-agent architecture
- Real-time planning
- PDF generation
- Email integration
- User authentication system

## 🛠 Tech Stack
- Python (Flask)
- Mistral AI (LLM)
- MongoDB
- HTML, CSS, JS

## ▶️ Run Locally
```bash
pip install -r requirements.txt
python app.py
